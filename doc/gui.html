scrcpy Windows GUI

コマンドラインのオプションを画面から編集し、未入力の項目は今までどおり scrcpy の既定値のまま起動します。映像のウィンドウは scrcpy 本体が開きます。

起動

リポジトリ直下で scrcpy-gui.bat を実行します。Python 3（Tk 付き）だけで動き、仮想環境や追加パッケージは要りません。

scrcpy-gui.bat
py -3 -m gui

起動できないときは %TEMP%\scrcpy-gui-error.txt を見てください。scrcpy 自体の入れ方は windows.md です。

画面でできること

  • 接続、映像、音声、カメラ、操作、端末、ウィンドウ、録画、仮想ディスプレイ、詳細の各オプションを編集する
  • 空欄・オフ・「指定しない」は引数にしない
  • 無線接続と新しいディスプレイは「フラグのみ」と「値を指定」を選べる
  • 完成したコマンドをその場で見て、コピーして起動する
  • 端末一覧、アプリ、カメラ、ディスプレイ、エンコーダをログに出す
  • プロファイルを %APPDATA%\scrcpyGUI\profiles に保存する

接続先（シリアル / USB / TCP / 無線）は一つだけにしてください。 -K -M -G は、キーボード・マウス・ゲームパッドのモードで指定します。 V4L2 は Linux 専用の項目です。

起動と停止

Ctrl+Enter で起動します。停止の 1 回目は scrcpy のウィンドウを閉じ、後始末を走らせます。ウィンドウが無いときと 2 回目はプロセスを強制終了します。

コンソール表示をオフにすると、取れた出力は画面下のログへ出ます。相対パスの録画ファイルは scrcpy.exe のフォルダに作られます。
