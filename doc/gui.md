# Windows GUI

scrcpy のコマンドラインオプションを画面から編集し、`scrcpy` をそのまま起動するランチャーです。ミラー映像のウィンドウは scrcpy 本体が開きます。この画面は設定と起動用です。

## 起動

リポジトリ直下で、次のどちらかを実行します。

```bat
scrcpy-gui.bat
```

```bat
py -3 -m gui
```

Python 3（標準の Windows インストーラ。Tk を含む）が必要です。仮想環境は使いません。追加のパッケージも要りません。

起動できないときは `%TEMP%\scrcpy-gui-error.txt` を確認してください。

## scrcpy 本体

次の順で `scrcpy.exe` を探します。

1. 画面に保存してあるパス
2. 環境変数 `SCRCPY`
3. PATH
4. WinGet / Scoop / Chocolatey の既知の場所

見つからなければ「参照」か「自動検出」を使います。`adb.exe` は、画面のパス、環境変数 `ADB`、scrcpy と同じフォルダ、PATH、Android SDK の `platform-tools` の順です。指定した adb は、起動時に環境変数 `ADB` として scrcpy へ渡します。

インストール方法は [windows.md](windows.md) です。

## オプション

`app/src/cli.c` にある起動オプションを、接続・映像・音声・カメラ・操作・端末・ウィンドウ・録画・仮想ディスプレイ・詳細に分けて並べています。

- 空欄、オフ、「指定しない」は引数に含めません。scrcpy の既定値のままです。
- チェックを付けると、そのフラグを付けます。例えば「映像を送らない」を有効にすると `--no-video` です。
- 「フラグのみ」は値なしの `--tcpip` や `--new-display` です。「値を指定」は `--tcpip=192.168.1.10` のようになります。
- 下段のコマンドが、実際に渡す引数です。シェルは通しません。
- 「追加の引数」は、そのコマンドの末尾にそのまま足します。引用符で囲んだ一つの値も書けます。
- 短い `-K` / `-M` / `-G` は、キーボード / マウス / ゲームパッドのモード選択で指定します。OTG のときは `aoa`、通常の物理入力は `uhid` です。
- `--help` と `--version`、各種 `--list-*` は設定ではなく、メニュー「端末」から実行します。結果は下のログに出ます。一覧には接続先と、カメラ ID・向き・映像ソース・ディスプレイ ID・ログレベルだけを引き継ぎます。
- V4L2 の項目は Linux 専用です。Windows では指定しても scrcpy は失敗します。

接続先（シリアル、USB 端末、TCP/IP 端末、無線接続）は一つだけにしてください。複数あると起動前に確認します。

端末が 1 台だけでシリアルが空なら、再読込でそのシリアルが入ります。複数台のときは一覧から選ぶとシリアル欄へコピーされます。

検索は、表示名、フラグ、説明に対して絞り込みます。Ctrl+F で検索欄へ移ります。

## 起動と停止

Ctrl+Enter でも起動します。

- 「scrcpy のコンソールを表示」がオフのとき、出力は下のログへ流します。scrcpy がコンソールへしか書かないメッセージは、このチェックを付けると別窓に出ます。
- 停止の 1 回目は、scrcpy のウィンドウへ閉じる操作を送ります。端末側の後始末（タップ表示やスリープ設定の復元）が走ります。
- ウィンドウがまだ無いとき、または 2 回目の停止は、プロセスを強制終了します。後始末が残ることがあります。
- 相対パスの録画ファイルは、`scrcpy.exe` があるフォルダに作られます。参照で選んだパスは絶対パスです。

終了コードは scrcpy と同じです。0 が正常、1 が起動失敗、2 が実行中の切断です。

## 保存場所

画面を閉じると、次の場所に前回の内容を保存します。リポジトリ内には書きません。

```text
%APPDATA%\scrcpyGUI\session.json
%APPDATA%\scrcpyGUI\profiles\
```

プロファイルはオプションと追加引数だけを復元します。scrcpy と adb のパスは、その PC の前回値のままです。

## ショートカット

実行中のキー操作は、画面の「ショートカット」タブにまとめてあります。MOD の既定は左 Alt または左 Super で、「ショートカット修飾キー」から変更できます。
